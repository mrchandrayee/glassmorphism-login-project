A responsive login screen recreated from the supplied 26-second video reference.

## Run
No build step or dependencies are required.

1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local HTTP server (optional):
```bash
python -m http.server 8000
```
Then visit http://localhost:8000.

## Included
- Soft blue/lavender gradient background and floating glass orbs
- Frosted-glass login card, email/password fields, remember-me checkbox
- Password visibility toggle and responsive layout
- Client-side form validation and demo feedback
- Google, Apple, and Facebook-style sign-in buttons (UI only)

## Important
The video primarily shows CSS source panels; the small on-screen code is not fully legible at the supplied video resolution. This project is a clean, runnable reconstruction of the visible interface, not a verbatim recovery of every source line. Authentication, password reset, registration, and social OAuth need a real backend/provider configuration.
